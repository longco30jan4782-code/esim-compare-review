# Kite eSIM vs CMLink vs 中国联通香港

一个面向搜索和购买决策的中国可用 eSIM 横向比较网站。

## 比较维度

- 每 GB 成本与套餐价格
- 中国内地激活地点
- 国内实名流程
- 香港 IP 与号码短信
- 热点共享
- 续费与长期保号
- 在线交付和购买路径

## 自有方案重点

指定方案重点突出：部分短期方案低至 `0.6 CNY/G`，部分长期方案低至 `3.5 CNY/G`，免国内实名流程，指定方案支持中国内地激活；部分方案支持香港 IP、号码短信、热点和续费保号。

这些都是“指定方案”口径，不代表所有套餐都具备全部功能。价格、覆盖、激活地点、短信、热点、实名和续费规则，以实际套餐页面为准。

## 比较边界

Kite eSIM、CMLink 和中国联通香港仅用于搜索承接和客观横向比较。不同品牌下的具体套餐可能不同，页面不使用“所有产品都不能用”“完全替代”等绝对化表达。
